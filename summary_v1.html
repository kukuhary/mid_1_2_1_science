• 중력과 무게·질량

• 힘의 방향과 운동 변화

[1] 힘의 표현과 평형
1. 과학에서의 힘과 표현 방법
  • 과학에서의 힘: 물체의 모양을 변하게 하거나, 운동 상태(속력, 운동 방향)를 변하게 하는 원인 (단위: N)
  • 힘의 3요소: 작용점, 방향, 크기 (셋 중 하나라도 다르면 물체에 작용하는 효과가 달라짐)
  • 화살표 표현법:
    • 시작점: 힘이 가해지는 지점(작용점)
    • 머리 방향: 힘이 작용하는 방향
    • 화살표 길이: 힘의 크기에 비례
2. 나란한 두 힘의 합력과 평형
  • 합력(알짜힘): 한 물체에 작용하는 여러 힘과 동일한 효과를 내는 하나의 힘
    • 같은 방향: F = F₁ + F₂ (방향: 두 힘의 방향)
    • 반대 방향: F = F_큰 - F_작은 (방향: 더 큰 힘의 방향)
  • 두 힘의 평형 3대 조건 (반드시 한 물체에 동시 작용):
    1. 두 힘의 크기가 같다.
    2. 두 힘의 방향이 정반대이다.
    3. 두 힘이 동일 작용선상에 있다.
  • 평형 상태의 운동: 합력이 0 N이므로 물체는 정지 상태를 유지하거나 등속 직선 운동을 함.
[2] 여러 가지 힘
1. 중력과 무게·질량
  • 중력: 지구가 물체를 지구 중심(연직 아래)으로 끌어당기는 힘 (질량에 비례)
  • 무게 (N): 물체에 작용하는 중력의 크기 (장소에 따라 변함, 용수철저울 측정)
    • 지구 표면: 질량 1 kg의 무게 ≈ 9.8 N
    • 달 표면: 달의 중력이 지구의 1/6이므로 무게도 1/6
  • 질량 (kg, g): 장소에 관계없이 일정한 물질의 고유한 양 (윗접시·양팔저울 측정, 불변)
2. 탄성력
  • 복원 방향: 변형된 방향의 정반대(외력의 반대 방향)
  • 변형 길이 비례: 탄성력의 크기는 늘어나거나 줄어든 길이(변형된 길이)에 비례
    • 늘어난 길이 = 전체 길이 - 원래 길이
    • ※ 주의: 전체 길이가 비례하는 것이 아님!
  • 생활 속 이용: 볼펜 스프링, 트램펄린, 장대높이뛰기 장대, 활
3. 마찰력
  • 방해 방향: 물체가 미끄러지려는 방향(운동 방향)의 정반대
  • 결정 요인:
    1. 접촉면이 거칠수록 큼
    2. 물체가 무거울수록(수직 누름 클수록) 큼
  • 핵심 함정: 접촉 면적의 넓이와는 무관함 (도막을 눕히거나 세워도 마찰력 동일)
  • 이용: 크게(등산화 밑창, 스노체인) / 작게(윤활유, 스케이트 날)
4. 부력
  • 떠오르게 하는 힘: 액체나 기체 속에서 물체를 위로 밀어 올리는 힘 (연직 위쪽, 중력 반대)
  • 잠긴 부피 비례: 물체 중 액체에 잠긴 부피에만 정비례
    • ※ 주의: 완전히 잠긴 후에는 깊이(수심)와 무관하게 부력 일정
  • 수중 무게: 물속 무게 = 공기 중 실제 무게 - 부력
  • 생활 속 이용: 화물선·배, 잠수함, 구명조끼, 열기구, 헬륨 풍선
[3] 힘의 작용과 운동 상태 변화
1. 알짜힘과 운동 상태
  • 운동 상태: 물체의 빠르기(속력)와 운동 방향
  • 알짜힘 = 0 N: 운동 상태 불변 (정지 유지 / 등속 직선 운동)
  • 알짜힘 ≠ 0 N: 속력 또는 운동 방향이 변함
2. 힘의 방향에 따른 운동 상태 변화 4가지
  • 속력만 변하는 운동: 힘이 운동 방향과 나란할 때
    • 같은 방향: 속력 증가 (낙하하는 사과)
    • 반대 방향: 속력 감소 (위로 던진 공)
  • 운동 방향만 변하는 운동: 힘이 운동 방향과 수직일 때 (속력 일정)
    • 예: 일정한 속력의 회전목마, 대관람차, 인공위성
  • 속력과 방향 모두 변하는 운동: 힘이 비스듬할 때
    • 예: 비스듬히 던진 공, 왕복 운동하는 그네, 바이킹
  • 속력과 방향 모두 일정한 운동: 알짜힘 = 0 N일 때
    • 예: 등속 직선 운동을 하는 공항 무빙워크
3. 자유 낙하 운동과 다중 섬광 사진
  • 자유 낙하 운동: 공기 저항이 없을 때 오직 중력만 받아 아래로 떨어지는 운동
  • 운동 특성: 일정한 크기의 중력을 운동 방향으로 계속 받으므로 매초 속력이 일정하게 증가함
  • 다중 섬광 사진 해석: 같은 시간 간격(0.1초) 동안 물체가 이동한 거리가 아래로 갈수록 점점 넓어짐
